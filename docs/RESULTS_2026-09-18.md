# FlyVL 결과 종합 (2026-09-18, 최종 갱신)

> **이 문서를 읽는 법.** 세션 중 열 건의 결과를 철회했고(§3), 판독 파이프라인도 두 번 고쳤다.
> 따라서 §1의 과거 수치는 **당시 설정에서의 기록**이며 서로 다른 실행의 절대값을 비교하면 안 된다.
> 지금 유효한 것은 **§0-1의 확정 표**뿐이다. 세부는 `PROTOCOL_P5_flytask.md`에 있다.

## 0. 한 줄 요약

**초파리 커넥톰을 범용 비전 인코더로 쓸 근거는 없다.** 그러나 이유는 "초파리가 단순해서"가 아니다.
**2,447만 개 연결이 이미 움직임 검출에 배정되어 있어서 범용 표현에 쓸 자유도가 남아 있지 않다.**
같은 배선·같은 dynamics·같은 readout인데 과제만 바꾸면 서열이 완전히 뒤집힌다.

## 1. 실험별 최종 수치 (과거 기록 — 설정이 서로 다름)

### 1-1. 학습 없는 frozen CNS + 선형 probe (V1 / P1-mini, CIFAR 5k, K=1024, 3 seed)

| rep | central_vnc | visual_projection |
|---|---|---|
| real | 29.5 | 31.9 |
| matched shuffle | 31.2 | 32.7 |
| global shuffle | 37.3 | 38.7 |
| pixels | 30.5 | – |
| stim_only (눈 입력) | 28.4 | – |
| random projection | 35.1 | – |

real − matched = **−1.7 / −0.8**, real − global = **−7.8**. 사전 등록 규칙(global 기준)상 P1-mini는 STOP.

### 1-2. dynamics를 task-optimize (v2-A, CIFAR 5k, 3 seed)

| | real | global shuffle |
|---|---|---|
| readout만 학습 (init) | 25.5 | 25.1 |
| dynamics까지 학습 | 27.4 | 26.9 |

real − shuffle = +0.5 [−1.2, +2.4], seed 부호 엇갈림 → **INCONCLUSIVE**. 학습 이득은 real +1.9 / shuffle +1.8로 동일.
gain·τ는 거의 움직이지 않고 변화는 주로 bias.

### 1-3. eye bypass, learned input (P2-B, 3 seed) / 앞뒤 번역기 + 뇌 없음 대조군 (P2-C, 1 seed)

| | real | shuffle | 뇌 없음 |
|---|---|---|---|
| P2-B learned input (visual_entry L1–L5) | 33.3 | 33.9 | – |
| P2-C front+back translators | 33.5 | 38.0 | **36.0** |

입력을 학습시키면 +6~7%p 오르지만 real ≈ shuffle이고, **뇌를 빼도 같거나 더 높다**(P2-C).
→ 이 조건에서 오른 성능은 번역기가 만든 것.

### 1-4. InternVL3-1B visual token distillation (P4, CIFAR 2k, 8 seed)

천장: teacher 원본 256토큰 **83.3**, 4×4 pooled **73.5**.

| rep | zero-shot |
|---|---|
| 작은 CNN | 36.3 |
| pixels (16 patch) | 27.9 |
| 눈 입력만 | 24.4 |
| real central (v2 g=1) | **24.5** |
| matched shuffle central | 23.4 |
| global shuffle central | 21.6 |
| 평균 토큰 (하한) | 10.0 |

| 비교 (central) | v2 (g=1), 8 seed | v1 LIF, 8 seed |
|---|---|---|
| real − matched | +1.11 [+0.27, +1.90] | +0.95 [−0.19, +2.19] |

| matched − global | +1.79 [+0.89, +2.73] | **−2.33 [−3.40, −1.24]** |

세 view(optic lobe / VPN / central)에서 v2 기준 real > matched > global 순서. v1에서는 global의 위치가 뒤집힌다.

### 1-5. 추가 채널로서의 뇌 (concat, 8 seed)

| rep | zero-shot |
|---|---|
| 눈 입력만 | 24.40 |
| + real central | **25.90** |
| + matched shuffle central | 25.25 |

+real − 눈 입력 = **+1.50 [+0.49, +2.55]** (8/8 seed 양수). +real − +matched = +0.65 [−0.19, +1.41] (4/8).
→ 뇌를 추가 채널로 붙이면 오르지만, **real 특이적이지는 않다.**

순서는 데이터 규모와 무관하게 유지. 마리 수(영역 분할)를 늘리면 네 조건 모두 오르지만 **pixels에서도 같은 크기로 오른다**
→ swarm 이득은 영역 분할 구조의 효과이고 초파리 특이적이지 않다.

### 1-7. VIC 기반 readout과 두 번째 대조군 그래프 (P4 결과 10·11, 8 seed)

| readout 집합 | real | matched shuffle | diff [CI] |
|---|---|---|---|
| central 전체 (59k) | 24.49 | 23.38 (s0) / 23.42 (s1) | +1.11 [+0.27, +1.90] / +1.06 [+0.24, +1.88] |
| VIC 상위 11k | 24.02 | 23.29 | +0.74 [−0.08, +1.54] |
| VIC 상위 11k (VPN 제외) | 23.68 | 22.00 | **+1.67 [+0.73, +2.62]** |

- 논문(VIC) 기준으로 시각 입력을 받는 뉴런만 읽어도 절대 성능은 오르지 않음 → 정보는 넓게 분산.
- 두 독립 matched shuffle 그래프가 0.05%p 차이로 일치 → 대조군 그래프 변동성은 무시할 수준이고,
  **real 우위(+1.1%p)는 그래프 seed·학습 seed 양쪽에서 재현됨.**

### 1-8. 초파리 도메인 과제 (P5, 2026-09-18)

| 과제 | 눈 입력 | real | matched shuffle |
|---|---|---|---|
| 움직임 방향 4종, 쉬움 (대비 0.25~0.45, 잡음 없음) | 33.3 | 99.4 (central) | 96.1 |
| **움직임 방향 4종, 어려움 (대비 0.04~0.10, 잡음 σ=0.06)** | 27.7 | **57.0 (central) / 55.6 (VPN)** | **37.8 / 39.6** |
| 다가옴 vs 멀어짐 | 97.8 | 100 | 100 (변별력 없는 과제) |

- 시간 평균 feature만 쓰는데도 눈 입력 33% → 뇌 통과 99%: **재귀 회로가 시간 정보를 공간 패턴으로 변환**.
- 쉬운 조건에서는 shuffle도 96~98% → 변환 자체는 재귀 네트워크의 일반 성질.
- **어려운 조건에서 real이 +16~19%p**: 자극 세트 3개 모두 재현, 독립 shuffle 그래프 2개가 1.4%p 이내로 일치.
- CIFAR에서의 real 우위(+1.1%p)와 비교해 **한 자릿수 이상 큰 효과**.

## 2. 재현성 있게 남은 것

0. **과제 의존성이 가장 크다** — 사물 분류에서는 뇌 통과가 손실이고 real−shuffle이 ±1%p, 저대비·잡음 움직임 과제에서는
   뇌 통과가 +30%p 이득이고 real−shuffle이 +16~19%p.
1. **frozen MaleCNS < pixels < 작은 CNN** — CIFAR 계열 모든 설정, 모든 데이터 규모에서 동일.
2. **뇌를 통과시키면 눈 입력보다 정보가 줄어든다** (P4 어떤 view도 눈 입력을 넘지 못함).
3. **global shuffle 대조군은 쓸 수 없다** — dynamics(v1/v2)와 readout(선형 probe/학습 정렬기)에 따라
   real 대비 −7.8%p에서 +2.9%p까지 움직인다. 이유: 영역 구조를 깨면 신호가 뇌 전체로 무작위 확산되어
   선형적으로 읽기 쉬워지고(V1), dynamics에 따라 전달량 자체가 크게 달라진다.
4. **real vs block-matched shuffle: 학습 정렬기에서는 real +1.1%p가 재현된다** (그래프 seed 2개 × 학습 seed 8개,
   두 그래프 모두 CI가 0을 넘음; VPN 제외 중추 뉴런만 읽으면 +1.67%p). 단 선형 probe에서는 부호가 반대(−1.7%p)로,
   **readout 종류에 따라 방향이 바뀐다.**
5. **seed 3개로는 이 크기의 효과를 판정할 수 없다** — 같은 비교가 3 seed에서 +1.53 [CI>0]이었다가
   8 seed에서 +0.65 [CI에 0 포함]으로 바뀐 사례가 있다.

## 3. 정정 이력 (모두 커밋으로 남김)

이 세션에서 **열 건**을 철회했다. **열 건 모두 우리에게 유리한 방향의 해석이었고, 조건을 맞추자 무너졌다.**

| # | 보고했던 것 | 무너진 이유 |
|---|---|---|
| 1 | V1 헤드라인 real 우위 | global shuffle은 무효한 대조군 (dynamics에 따라 순위가 뒤집힘) |
| 2 | P4 결과 4 (+1.53%p, CI>0) | 3 seed → 8 seed에서 +0.65%p, CI에 0 포함 |
| 3 | "뇌가 없던 정보를 만든다" | 눈 기준선을 시간평균으로 불리하게 설정한 탓 |
| 4 | MLP 대비 +11.5%p | 기준선에 시간 귀납편향이 없었음 (GRU가 초파리를 이김) |
| 5 | 섞은 배선 대비 +72%p | 20 epoch 미수렴을 능력 차이로 오독 (50 epoch에서 47.1%, 상승 중) |
| 6 | "중추가 정보를 희석한다" | 판독 방식 artifact (시각엽은 graded라 시간평균이 상쇄) |
| 7 | "시각엽만 쓰면 된다" | 사후 영역 선택 |
| 8 | "데이터 부족 탓" | 데이터 5배에도 격차 유지 |
| 9 | "회로가 시간 구조를 선형화한다" | 투영 폭 + PCA 성분 수 병목. K=2048에서 시계열 = 시간평균 |
| 10 | "흔들림은 섞은 배선을 더 돕는다" | 독립 matched 그래프 2개가 +4.10 / +1.17로 엇갈림 |

**도구 결함도 네 건 고쳤다**: 투영 seed가 `hash()` 기반이라 프로세스마다 달랐던 것,
광수용체 잡음에 seed가 없어 실행 간 3.6%p 변동, 결과 JSON이 덮어써져 `real` 행이 사라진 것(두 스크립트),
인자 파싱 순서 오류.

## 4. 원래 목표(FlyVL) 관점에서의 현재 위치

**닫혔다.** 눈 단계까지 검증했고(§P7), 반론 여지를 남기지 않았다.
- 눈이 픽셀 대비 3.4%p를 잃는 원인은 앨리어싱·해상도·적응이 아니라 **흔들림 부족**이었고, 고쳐도
  커넥톰에 유리하지 않았다(real +1.60 / shuffle +1.17~+4.10, 서열 불변).
- 뇌 없는 무작위 투영이 real을 넘는다. 커넥톰을 통과시켜 얻는 것이 무작위 행렬 곱 한 번만 못하다.

## 5. 남은 것

실험으로 새로 확인할 것은 마땅치 않다. 인코더 질문은 닫혔고, 움직임 결과는 자극 세트 2개·대조군 4종으로
복제됐으며, 외부 프로젝트 비교도 마쳤다(`docs/survey_fly_chess_2026-09.md` — 실력을 보고하는 프로젝트는
전부 수백만 파라미터를 학습시키고, 순수 고정 커넥톰만 쓴 유일한 프로젝트는 실력을 보고하지 않는다).

생물학 쪽으로 넘어간다면: (a) 사물 분류에서 real이 shuffle보다 **낮은** 이유의 분해,
(b) 부호 반전을 하나의 틀로 설명하는 실험. 둘 다 원래 목표는 아니다.

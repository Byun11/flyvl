# FlyVL 결과 종합 (2026-09-18 07시 기준)

이 문서는 V1 → v2-A → P2-B/C → P4와 그 재검증까지의 **최종 상태**를 모은 것이다.
개별 사전 등록과 원자료는 `PROTOCOL*.md`, `results/`에 있다. 중간에 철회·정정된 결론은 아래 "정정 이력"에 남겼다.

## 0. 한 줄 요약

CIFAR-10에서 **frozen MaleCNS를 이미지 인코더로 쓰면 픽셀·작은 CNN보다 낮다.** 배선을 섞은 대조군과의
비교는 **대조군 종류와 dynamics 가정, seed 수에 따라 부호가 바뀔 정도로 작다**(±1~3%p). 실험을 통해
가장 재현성 있게 남은 것은 방법론적 결과다: **global shuffle은 대조군으로 쓸 수 없고, block-matched shuffle과
최소 8 seed가 필요하다.**

## 1. 실험별 최종 수치

### 1-1. 학습 없는 frozen CNS + 선형 probe (V1 / P1-mini, CIFAR 5k, K=1024, 3 seed)

| rep | central_vnc | visual_projection |
|---|---|---|
| real | 29.5 | 31.9 |
| matched shuffle | 31.2 | 32.7 |
| global shuffle | 37.3 | 38.7 |
| pixels | 30.5 | – |
| stim_only (눈 입력) | 28.4 | – |
| random projection | 35.1 | – |

real − matched = **−1.7 / −0.8**, real − global = **−7.8**. 사전 등록 규칙(global 기준)상 P1-mini는 STOP.

### 1-2. dynamics를 task-optimize (v2-A, CIFAR 5k, 3 seed)

| | real | global shuffle |
|---|---|---|
| readout만 학습 (init) | 25.5 | 25.1 |
| dynamics까지 학습 | 27.4 | 26.9 |

real − shuffle = +0.5 [−1.2, +2.4], seed 부호 엇갈림 → **INCONCLUSIVE**. 학습 이득은 real +1.9 / shuffle +1.8로 동일.
gain·τ는 거의 움직이지 않고 변화는 주로 bias.

### 1-3. eye bypass, learned input (P2-B, 3 seed) / 앞뒤 번역기 + 뇌 없음 대조군 (P2-C, 1 seed)

| | real | shuffle | 뇌 없음 |
|---|---|---|---|
| P2-B learned input (visual_entry L1–L5) | 33.3 | 33.9 | – |
| P2-C front+back translators | 33.5 | 38.0 | **36.0** |

입력을 학습시키면 +6~7%p 오르지만 real ≈ shuffle이고, **뇌를 빼도 같거나 더 높다**(P2-C).
→ 이 조건에서 오른 성능은 번역기가 만든 것.

### 1-4. InternVL3-1B visual token distillation (P4, CIFAR 2k, 8 seed)

천장: teacher 원본 256토큰 **83.3**, 4×4 pooled **73.5**.

| rep | zero-shot |
|---|---|
| 작은 CNN | 36.3 |
| pixels (16 patch) | 27.9 |
| 눈 입력만 | 24.4 |
| real central (v2 g=1) | **24.5** |
| matched shuffle central | 23.4 |
| global shuffle central | 21.6 |
| 평균 토큰 (하한) | 10.0 |

| 비교 (central) | v2 (g=1), 8 seed | v1 LIF, 8 seed |
|---|---|---|
| real − matched | +1.11 [+0.27, +1.90] | +0.95 [−0.19, +2.19] |
| real − global | +2.90 [+1.96, +3.85] | **−1.38 [−2.45, −0.25]** |
| matched − global | +1.79 [+0.89, +2.73] | **−2.33 [−3.40, −1.24]** |

세 view(optic lobe / VPN / central)에서 v2 기준 real > matched > global 순서. v1에서는 global의 위치가 뒤집힌다.

### 1-5. 추가 채널로서의 뇌 (concat, 8 seed)

| rep | zero-shot |
|---|---|
| 눈 입력만 | 24.40 |
| + real central | **25.90** |
| + matched shuffle central | 25.25 |

+real − 눈 입력 = **+1.50 [+0.49, +2.55]** (8/8 seed 양수). +real − +matched = +0.65 [−0.19, +1.41] (4/8).
→ 뇌를 추가 채널로 붙이면 오르지만, **real 특이적이지는 않다.**

| 눈 입력 | 16.6 | 19.0 | 24.6 |

순서는 데이터 규모와 무관하게 유지. 마리 수(영역 분할)를 늘리면 네 조건 모두 오르지만 **pixels에서도 같은 크기로 오른다**
→ swarm 이득은 영역 분할 구조의 효과이고 초파리 특이적이지 않다.

### 1-7. VIC 기반 readout과 두 번째 대조군 그래프 (P4 결과 10·11, 8 seed)

| readout 집합 | real | matched shuffle | diff [CI] |
|---|---|---|---|
| central 전체 (59k) | 24.49 | 23.38 (s0) / 23.42 (s1) | +1.11 [+0.27, +1.90] / +1.06 [+0.24, +1.88] |
| VIC 상위 11k | 24.02 | 23.29 | +0.74 [−0.08, +1.54] |
| VIC 상위 11k (VPN 제외) | 23.68 | 22.00 | **+1.67 [+0.73, +2.62]** |

- 논문(VIC) 기준으로 시각 입력을 받는 뉴런만 읽어도 절대 성능은 오르지 않음 → 정보는 넓게 분산.
- 두 독립 matched shuffle 그래프가 0.05%p 차이로 일치 → 대조군 그래프 변동성은 무시할 수준이고,
  **real 우위(+1.1%p)는 그래프 seed·학습 seed 양쪽에서 재현됨.**

## 2. 재현성 있게 남은 것

1. **frozen MaleCNS < pixels < 작은 CNN** — 모든 설정, 모든 데이터 규모에서 동일.
2. **뇌를 통과시키면 눈 입력보다 정보가 줄어든다** (P4 어떤 view도 눈 입력을 넘지 못함).
3. **global shuffle 대조군은 쓸 수 없다** — dynamics(v1/v2)와 readout(선형 probe/학습 정렬기)에 따라
   real 대비 −7.8%p에서 +2.9%p까지 움직인다. 이유: 영역 구조를 깨면 신호가 뇌 전체로 무작위 확산되어
   선형적으로 읽기 쉬워지고(V1), dynamics에 따라 전달량 자체가 크게 달라진다.
4. **real vs block-matched shuffle: 학습 정렬기에서는 real +1.1%p가 재현된다** (그래프 seed 2개 × 학습 seed 8개,
   두 그래프 모두 CI가 0을 넘음; VPN 제외 중추 뉴런만 읽으면 +1.67%p). 단 선형 probe에서는 부호가 반대(−1.7%p)로,
   **readout 종류에 따라 방향이 바뀐다.**
5. **seed 3개로는 이 크기의 효과를 판정할 수 없다** — 같은 비교가 3 seed에서 +1.53 [CI>0]이었다가
   8 seed에서 +0.65 [CI에 0 포함]으로 바뀐 사례가 있다.

## 3. 정정 이력 (모두 커밋으로 남김)

| 시점 | 처음 보고 | 정정 후 |
|---|---|---|
| P0-2 | CUDA backend에서 G1 FAIL → 모델 불안정 의심 | cuSPARSE 비결정성이 원인. cpu_deterministic으로 PASS |
| P4 결과 1 | real − matched = 차이 없음 (3 seed) | 8 seed에서 +1.11 [CI>0] (결과 6) |
| P4 결과 4 | eye+real이 eye+matched보다 +1.53 [CI>0] | 8 seed에서 +0.65 [CI에 0 포함] → **철회** (결과 5) |
| V1 | real이 shuffle보다 −7.8%p | matched shuffle 대비로는 −1.7%p (P1-mini 재검증) |
| 보고 과정 | 알림 스트림의 일부 수치를 그대로 인용 | 깨진 알림이 섞여 있어 이후 모든 수치를 결과 파일에서 확인 |

## 4. 원래 목표(FlyVL) 관점에서의 현재 위치

- **Q1 (학습 없는 frozen CNS가 유용한가):** NO.
- **Q2 (dynamics 학습 시 real > shuffle인가):** INCONCLUSIVE, 효과 크기 ±1%p.
- **Q3 (sensory alignment가 병목인가):** 부분적으로 YES(+6~7%p). 그러나 뇌를 빼도 같은 이득.
- **Q4 (swarm이 해상도를 보완하는가):** YES지만 초파리 특이적이지 않음.
- **Q5 (CLIP/VLM semantic space에 정렬되는가):** 정렬 자체는 가능(zero-shot 24~26%, 천장 73.5%).
  그러나 pixels(27.9%)·CNN(36.3%)보다 낮아 **초파리 뇌를 쓰는 이유를 성능으로 정당화할 수 없다.**
- **Q6 (connectome backbone VLM):** 구현은 가능하지만, 현재 근거로는 "가능하다" 이상의 주장을 할 수 없다.

## 5. 다음에 할 수 있는 것 (근거 있는 순서)

1. **초파리 도메인 과제** (looming 회피, 움직임 방향, 조향) + real / matched shuffle / 뇌 없음, 8 seed 이상.
   P0-1에서 망막 경로만으로 LPLC2/LC4 → DNp01 lateralized 반응이 확인됐고, FlyGM 논문은 제어 과제에서
   degree 보존 대조군 대비 real 우위를 보고했다. 지금까지의 음성 결과와 가장 다른 조건이다.
2. **배선 비용·거리 보존 shuffle** (`syn-points` 12.7 GB 필요). Correig-Fraga et al.가 real 우위를 보인 유일한 대조군 조건.
3. **VIC 기반 readout 뉴런 선택** (논문의 시각 입력 받는 central 약 1.1만 개) — 지금은 central 5.9만 개 전체를 읽는다.
4. 위에서 뭔가 나오면 CLIP distillation → LLM 연결로 확장.

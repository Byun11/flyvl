# 초파리 커넥톰을 비전 인코더로 쓸 수 있는가 — 결과 보고

2026-09. 재료: MaleCNS v1.0 (166,700 뉴런 / 25,582,938 방향성 연결), GPU 1대.
세부 기록은 `PROTOCOL_P5_flytask.md`, 수치 검증은 `scripts/audit_claims.py`로 재현할 수 있다.

## 질문
ViT 자리에 측정된 초파리 커넥톰을 넣어 이미지 인코더로 쓸 수 있는가.

## 방법
- **배선은 고정.** 커넥톰은 한 번도 변경하지 않는다. 학습 대상은 미공개인 생리 파라미터
  (세포 타입별 이득·시상수·bias, 47,524개)와 선형 판독기뿐이다.
- **판독 뉴런 집합은 사전 등록.** real 그래프에서 뉴런 ID로 고정하고 모든 조건에 동일 적용한다.
- **대조군은 재배선 그래프.** 차수·전달물질 부호·영역별 연결 통계를 보존한 채 연결 상대만 섞는다.
  각 대조군을 **독립 그래프 2~3개**씩 만들어 평균과 SD로 보고한다.
- **판정 기준**: |차이| / SD(대조군 분포) ≥ 2. real이 대조군 분포의 이상치인지를 묻는 것이므로
  분모는 SD이며 SE가 아니다. 3표본 SD는 거칠어 이 문턱은 정밀 검정이 아닌 선별 기준이다.

## 결과 1 — 사물 분류: 커넥톰은 도움이 되지 않는다
CIFAR-10, train 3,000 / test 1,000, 선형 probe (K=1024), chance 10%.

| 조건 (visual_projection 판독) | acc |
|---|---|
| **global shuffle** (가장 많이 섞음, n=3) | **36.47 ± 0.55** |
| 시각엽만 섞기 (n=2) | 33.72 ± 0.16 |
| matched shuffle (n=3) | 33.40 ± 1.31 |
| 중추만 섞기 (n=3) | 33.50 ± 1.61 |
| **real (실제 배선)** | **32.10** |
| 무작위 투영 (뇌 없음) | 31.90 |
| 픽셀 원본 | 29.17 |
| 눈 입력만 | 28.00 |

**섞을수록 좋아진다.** real은 모든 재배선 대조군보다 낮거나 같고, **뇌를 거치지 않은 무작위 투영(31.90)과
동급**이다. 2,447만 엣지를 25 step 돌린 순이익이 무작위 행렬 한 번 곱한 것과 다르지 않다.
InternVL3-1B 토큰 정렬 실험도 같은 결론이었다(초파리 24.5 / 눈 입력 24.4 / 픽셀 27.9 / 작은 CNN 36.3 /
teacher 천장 73.5).

## 결과 2 — 저조도 움직임 판별: 커넥톰이 크게 앞선다
4방향 드리프트 격자, 대비 0.04~0.10, 광수용체 잡음 σ=0.06, n=3,000, chance 25%.

| 조건 (visual_projection 판독) | acc | real 대비 (차이/SD) |
|---|---|---|
| 중추만 섞기 (n=3) | 79.26 ± 2.23 | +1.22 (0.5, **판별 불가**) |
| **real** | **78.04** | – |
| matched shuffle (n=3) | 62.22 ± 2.50 | −15.81 (6.3) |
| 시각엽만 섞기 (n=2) | 62.06 ± 4.01 | −15.98 (4.0) |
| **global shuffle** (n=3) | **52.43 ± 1.20** | −25.60 (21.3) |

**섞을수록 나빠진다.** 그리고 **배선의 가치는 전적으로 시각엽에 있다** — 시각엽만 섞어도 전부 섞은 것과
같은 손상이 나고(62.06 vs 62.22), 중추만 섞으면 real과 구분되지 않는다.

## 결과 3 — 같은 배선이 한 과제에서 최고이고 다른 과제에서 최하위
| 배선 | 움직임 | CIFAR |
|---|---|---|
| **real** | **78.04 (1위)** | 32.10 (최하위권) |
| matched | 62.22 | 33.40 |
| **global** | **52.43 (최하위)** | **36.47 (1위)** |

**이것이 결과 1의 이유다.** 커넥톰이 범용 인코더가 되지 못하는 것은 초파리가 단순해서가 아니라,
2,447만 개 연결이 **이미 움직임 검출에 배정되어 있어 범용 표현에 쓸 자유도가 남아 있지 않기** 때문이다.
그 배정을 무작위로 풀면(global shuffle) 사물 분류가 오히려 좋아진다.

**부수 증거**: 동일한 시각엽 재배선 그래프 2개의 SD가 움직임에서 4.01, CIFAR에서 0.16으로 **25배 차이난다.**
시각엽 배선의 세부는 움직임 성능만 좌우하고 사물 분류에는 영향이 없다.

## 결과 4 — 그 계산 자체는 특별하지 않다
같은 과제(대비 0.015~0.040), 같은 눈 영상, 같은 데이터 예산(train 2,100 / test 900).

| 모델 | acc | 학습 파라미터 |
|---|---|---|
| **GRU (뇌 없음)** | **100.00** | 282,500 |
| real 배선 + 생리 학습 | 99.50 | 51,624 |
| **Hassenstein-Reichardt 상관기** (1956) | **98.15** | 12,804 |
| 2층 MLP | 87.96 | 20,742,400 |

초파리 회로가 저조도 움직임을 푸는 것은 사실이지만, **일반 순환 모델이 더 잘하고 교과서 상관기가
1/4 파라미터로 따라잡는다.** 공학적으로 커넥톰을 돌릴 이유가 없다.

## 눈 단계 검증 (반론 차단)
"눈 모델이 나빠서 진 것 아닌가"를 배제했다. 눈은 R1-6 광수용체 3,241개가 **서로 다른 시선 방향 800개**를
이루고(좌 292 / 우 508), 이미지를 보는 것은 **437개** = CIFAR 픽셀당 0.43 샘플이다.

| 가설 | 검증 | 판정 |
|---|---|---|
| 앨리어싱 | 샘플링 전 이미지 흐림 0~1.5 px | 기각 (≤ +1.0%p) |
| 해상도 부족 | 픽셀을 21×21로 축소 → 30.60 (32×32는 29.17) | 기각 |
| 광수용체 적응 | τ 0.5 → 2 → ∞ | 기각 (+0.2%p) |
| **흔들림 부족** | drift 0.2 → 1.2 | **지지** (+2.23%p) |

흔들림을 키우면 눈 입력이 25.77 → 28.00으로 오른다. 그러나 **고쳐도 커넥톰에 유리하지 않다** —
real은 +1.60%p, 대조군은 +1.17 ~ +4.10%p 오르며 서열이 바뀌지 않는다.

## 한계
1. **생리는 공개되지 않았다.** 논문이 공개한 것은 배선(연결·시냅스 수·전달물질 부호)뿐이다. 시상수·이득·
   발화 문턱과 광수용체 특성은 우리 구성물이다. 따라서 **절대 성능값은 모델 가정에 의존**하며,
   조건 간 비교(real vs 재배선)만 의미가 있다.
2. **동역학 의존성**: 같은 배선·같은 과제에서 v1 LIF는 57%, v2 rate(학습 전)는 32%였다. 결론을 단일
   동역학에 걸면 안 된다.
3. 자극은 합성이다. 자연 영상·실제 로봇 환경에서는 검증하지 않았다.
4. 미판정 3건: visual_projection 판독의 1.2~1.4%p 차이들로, real이 대조군 분포 안에 있어
   **대조군을 늘려도 해결되지 않는다.**

## 작업 과정에 대한 기록
결과 열네 건을 철회했다. **열네 건 모두 우리에게 유리한 방향의 해석이었고, 조건을 맞추거나 반복하자
무너졌다.** 대표적으로:
- "MLP 대비 +11.5%p" → 기준선에 시간 귀납편향이 없었다. GRU를 세우자 소멸.
- "섞은 배선 대비 +72%p" → 대조군이 20 epoch에 미수렴한 것을 능력 차이로 오독.
- "real 우위 +18.7%p" → 대조군 그래프 3개 중 **가장 낮은 하나**로 계산한 값. 실제로는 +15.8%p.
- "CIFAR에서 중추가 더 큰 걸림돌" → 중추 그래프 1개만 보고 쓴 것. 3개 평균에서 차이 소멸.

도구 결함 네 건도 수정했다(투영 seed가 프로세스마다 달랐던 것, 광수용체 잡음 미고정으로 실행 간 3.6%p 변동,
결과 파일 덮어쓰기, 인자 파싱 순서). 재발 방지를 위해 `scripts/audit_claims.py`가 모든 주장을
대조군 SD 대비로 기계 점검한다.

## 결론
**초파리 커넥톰을 범용 비전 인코더로 쓸 근거는 없다.** 다만 이유는 "초파리가 단순해서"가 아니라
**커넥톰이 특정 문제(움직임 검출)에 배정된 구조적 제약이고, 그 배정이 다른 문제에서는 순수한 손해**이기
때문이다. 그리고 그 배정이 만드는 계산조차 12,804 파라미터짜리 고전 모델로 재현된다.

## 결과 5 — P9: 사물 분류 결손의 원인은 경로 길이가 절반, 나머지는 배선 전체에 퍼져 있다
사전 등록: `PROTOCOL_P9_bottleneck.md`. real 엣지 중 무작위 비율 f만 global 방식으로 재배선해 real(f=0)과
global(f=1) 사이를 잇는다. 모든 수치는 **같은 머신에서 새로 측정**했다(이전 머신과는 움직임 과제의 잡음 난수가
달라 절대값이 약 2.7%p 다르다; CIFAR는 소수점까지 재현).

| 그래프 | 중추까지 평균 hop | CIFAR (VPN) | CIFAR (central) | 움직임 (VPN) | 움직임 (central) |
|---|---|---|---|---|---|
| **real** | **3.60** | 32.10 | 28.50 | **80.78** | **79.33** |
| f = 0.001 (n=2) | 3.07 | 31.75 | 30.10 | 79.72 | 77.28 |
| f = 0.01 (n=2) | 2.59 | 33.00 | 32.25 | 77.93 | 76.44 |
| f = 0.1 (n=3) | 2.06 | 34.20 | 34.33 | 80.73 | 75.06 ± 1.51 |
| f = 0.3 (n=2) | 1.96 | 34.05 | 34.35 | 76.85 | 75.87 |
| matched (n=3) | 2.84 | 33.43 | 32.91 | 64.74 | 63.37 |
| **global** (n=3) | **1.87** | **36.43** | **38.30** | **50.47** | **54.67** |

1. **real은 눈→중추 경로가 길다** (3.60 hop, 3 hop 안에 닿는 중추 뉴런 39%; 재배선은 전부 ≥96%).
   엣지 1%만 무작위로 옮겨도 hop 격차의 58%가 사라진다(소세계 효과).
2. **그러나 CIFAR는 hop을 절반만 따라간다.** 30% 재배선으로 hop 격차는 95% 회복되지만 CIFAR 격차는
   48%(VPN) / 60%(central)만 회복된다. VPN 판독에서는 사전 등록 기준상 **병목 가설 기각**, central은 **부분 지지**.
   → 재배선이 사물 분류를 돕는 이유의 절반쯤이 짧은 경로이고, 나머지는 30% 넘게 섞어야 풀리는 분산된 구조다.
3. **신호 감쇠로는 설명되지 않는다.** matched는 real보다 중추 도달 신호가 오히려 약한데(반응비 0.15 vs 0.22)
   CIFAR는 더 높다.
4. **움직임 계산은 부분 재배선에 강하다.** 엣지 30%를 옮겨도 3~4%p만 떨어진다. 반면 matched(블록 안에서 100%
   재배선)는 hop이 f=0.001~0.01 수준인데도 16%p 떨어진다 → 움직임 성능을 좌우하는 것은 경로 길이가 아니라
   **엣지 대부분의 구체적 배치**다.
5. **교환관계 (P-D)**: central 판독, f=0.1에서 움직임이 real보다 4.27%p 낮다(|d|/SD = 2.8, n=3) → 사전 등록 기준상
   "분리 불가능". 단 크기는 비대칭이다: CIFAR 격차의 59%를 회복하는 대가로 움직임 격차(real−global)의 17%만 잃는다.
   VPN 판독에서는 움직임이 real과 같다(80.73).

## 결과 6 — 영상 → 초파리 선택 → VLM: 파이프라인은 되지만 초파리는 흐림 한 번으로 대체된다
최종 목표 구조를 처음으로 끝까지 돌렸다: 저대비·잡음 영상에서 선택기가 움직이는 칸을 고르고,
InternVL3-1B가 그 칸(페이지의 1/16)만 보고 글자를 읽는다. 모두 real 배선, 같은 머신, 선택기만 바꿨다.

| 단계 | 과제 | 초파리 | 공짜 기준선 |
|---|---|---|---|
| V1 | 움직이는 사분면 (눈 좌표) | **97.67** (VPN) | 프레임 차이 94.00 |
| V2b | 움직이는 칸 16개 중 (눈 좌표) | **82.89** (시각엽 에너지) | 프레임 차이 73.56 |
| V3c | 같은 과제, 픽셀 영상, 시선 4번 | **98.33** | 픽셀 프레임 차이 95.78 |
| V3e | 글자 영상 → InternVL 정답률 | **92.33** (시각엽 변화 에너지) | 프레임 차이 80.33 |
| **V3f** | 같은 과제 | 92.33 | **흐림 2px + 프레임 차이 98.11** (정답 칸 상한 98.22) |
| V3g | 더 어려운 4개 조건 (칸 찾기) | 66.0 / 86.4 / 53.0 / 18.1 | **89.2 / 89.2 / 60.6 / 34.6** |

1. **선택기는 필요하다.** 정지 화면 전체를 주면 InternVL은 11.9%, 선택기가 고른 1/16만 주면 92~98%.
2. **초파리는 순진한 프레임 차이는 매번 이긴다** — 같은 샘플 수에서 +3.7 ~ +12%p.
3. **그러나 공간 흐림 한 번을 더한 프레임 차이에는 모든 조건에서 진다** (5개 조건). 초파리의 잡음 강건성은
   공간·시간 평균이고, 그건 공짜로 얻을 수 있다. P5에서 HR 상관기(1956)가 초파리를 따라잡은 것과 같은 패턴.
4. 읽는 방식이 결과를 크게 바꿨다: 시각엽 부호 평균 13.8% → 에너지 82.9% (V2), 정지 글자 영상에서 에너지 77.2% →
   **변화** 에너지 93.6% (V3e). 틀린 가설도 기록했다: 적응 단계(V3d)는 39.4%로 악화, 수용장 추정 묶기(V3h)는 42.6%.

## 결과 7 — P10: 움직임 우위는 스펙트럼 반경 착시가 아니다
다른 프로젝트에서 real>shuffle 우위가 스펙트럼 반경(ρ, 순환 증폭) 차이로 드러난 일이 있어 검사했다.
시각엽 순환 블록의 ρ는 real 0.915, matched ~0.51, global 0.268로 **P5 성능 순서와 정확히 같았다.**
사전 등록(`PROTOCOL_P10_spectral.md`) 후 ρ만 맞춰 다시 쟀다 (같은 머신, visual_projection):

| 조건 | 정확도 |
|---|---|
| **real** (ρ 0.915) | **80.78** |
| matched (ρ ~0.51) | 64.74 ± 1.33 |
| matched, ρ → 0.915 | 51.63 ± 1.32 |
| 시각엽만 재배선, ρ → 0.915 | 51.26 ± 1.00 |
| global, ρ → 0.915 | 44.32 ± 2.19 |
| real, ρ → 0.515 | 44.44 |

- ρ를 맞추면 격차는 **줄지 않고 커진다** (+16.0 → +29.2%p, 22 SD). 재배선 그래프는 증폭을 키우면 잡음도 키운다.
- real의 ρ를 낮추면 matched보다도 떨어진다. 시각엽 에너지 판독은 77.4%로 남아 있어, 무너지는 곳은 시각엽 → 시각투사 전달이다.
- → **real 배선은 자기 증폭 수준에서만 작동하는 "배선 + 이득" 한 쌍이다.** P5 결론(움직임에서 real 배선이 재배선을 이김)은 유지된다.
  단, 결과 4·6의 결론(고전 방법 — HR 상관기, 흐림 프레임 차이 — 이 같은 일을 한다)도 그대로다.

## 결과 8 — 방향 선택성도 고전 방법이 가져간다
조사에서 초파리가 이길 여지가 가장 크다고 나온 선택성 과제를 시험했다. 16칸 글자 영상에서 두 칸이 반대 방향으로
움직이고, InternVL3-1B는 **왼쪽으로** 움직이는 칸의 글자를 읽어야 한다.

| 선택기 | 칸 찾기 | VQA |
|---|---|---|
| 흐림 2px HR 상관기 픽셀 배열 (≡ 움직임 에너지) | **100.00** | **98.33** (= 정답 칸 상한) |
| 초파리 시각엽 변화 에너지 | 70.78 | 70.11 |
| 흐림 2px 프레임 차이 (방향 정보 없음) | 45.89 | 46.33 |

초파리 출력에는 방향 정보가 분명히 있지만(프레임 차이 +24%p), 1956년 상관기를 픽셀에 깐 것이 만점이다.
결과 4(HR 상관기 ≈ 초파리)와 결과 6(흐림 프레임 차이 > 초파리)에 이어 세 번째로 같은 결론이다:
**초파리 시각엽이 하는 계산은 실재하지만, 같은 계산을 하는 고전 모델이 더 싸고 더 정확하다.**

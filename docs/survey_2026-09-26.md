## 0. 한 줄 요약
**모든 출처가 우리 결론과 같은 선을 긋는다.** 측정 배선이 강한 대조군을 이기는 곳은 세 가지뿐이다:
**(1) 폐루프 몸 제어, (2) 특정 입력→특정 출력 라우팅(반사), (3) 손상·하이퍼파라미터 강건성.**
정지 이미지와 일반 학습에서는 지고, 그중 상당수의 "승리"는 차수 통계·자기 루프·스펙트럼 반경 같은
배선 이외의 원인이었다. **고전 기준선(HR, 흐림 프레임 차이)과 비교한 연구는 없고, 커넥톰을 VLM·토큰
선택기에 쓴 연구도 없다** — 우리 영상 파이프라인은 새로운 시도다.

## 2. 우리와 같은 결론 (배선 이점 없음)
- [Dhiman 2604.04033](https://arxiv.org/abs/2604.04033): 같은 무작위 초기화 + 차수 보존 대조군이면 flyvis 이점 소멸 (+0.0003).
- [Kuklev 2609.24565](https://arxiv.org/abs/2609.24565) (9/21): 고정 flyvis 인코더 0.857 < **광수용체만 0.891** < 작은 CNN 0.959.
- [FLY-lab](https://github.com/Recluse/FLY-lab): 커넥톰 30/30, **두 줄짜리 규칙도 30/30**.

## 3. 우리에게 직접 걸리는 경고
- **스펙트럼 반경 교란** ([fly-connectome-lab #74](https://github.com/akhmialeuski/fly-connectome-lab/issues/74)):
  real ρ=0.737 vs shuffle 0.257로 +5.8 우위가 생겼다가 재검증 중. **우리 P5 +16%p도 같은 교란 가능**
  (v2 기록: real ρ=1.0 vs global 0.29). → 반경·평균 활동을 맞춘 대조군으로 재확인 필요.
- **제어 사다리** (Dhiman + Therianos): 같은 초기화 / 차수·가중치 보존 / 세포 클래스 보존 / 크기 맞춤.

## 4. 공학 기준선 — 초파리식이 실제로 이기는 조건
- 수학적 사실: 정교화된 Reichardt 검출기 ≡ **Adelson-Bergen 움직임 에너지** ([van Santen & Sperling 1985](https://opg.optica.org/josaa/abstract.cfm?uri=josaa-2-2-300)).
  차이는 전처리 필터이고, 흐림 2px가 그걸 공짜로 줬다 → **우리 V3f 결과는 이론과 일치**.
- 초파리식이 이기는 곳은 **센서**(이벤트·광자, [Fu 2607.05205](https://arxiv.org/html/2607.05205): 야간 프레임 모델은 실패, 이벤트판은 유지),
  **예산**(Loihi 7 mW vs GPU 2 W, [TU Delft](https://mavlab.tudelft.nl/fully_neuromorphic_drone/)),
  **선택성**(looming·방향·자기 운동 제거, [LGMD 55k 파라미터 AUC 0.913 ≥ VGG16](https://iopscience.iop.org/article/10.1088/2634-4386/add0da)).
  **가우시안 잡음 프레임에서의 위치 찾기는 이 셋 중 어디에도 없다** — 우리가 진 조건이다.
- 토큰 선택 표준 기준선: [Run-Length Tokenization](https://arxiv.org/abs/2411.05222) (패치 L1 차이 임계값, 토큰 80% 감소),
  [EventPrune](https://arxiv.org/abs/2605.19506). 둘 다 프레임 차이와는 비교 안 함.

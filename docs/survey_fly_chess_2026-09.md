# 서베이: 커넥톰으로 체스 두는 프로젝트들 (2026-09)

우리 실험과 같은 재료(MaleCNS v1.0 / FlyWire)를 쓰면서 체스를 두는 공개 프로젝트를 조사했다.
계기는 SNS에 돌던 FliPy 영상이다. 목적은 **그들이 실제로 무엇을 학습시키는가**를 확인해, 우리 결과
(커넥톰의 기여가 작고 학습된 판독기가 대부분을 한다)와 대조하는 것이다.

## 1. 프로젝트별 방식

| 프로젝트 | 커넥톰 | 고정 / 학습 | 보고된 실력 | 대조군 |
|---|---|---|---|---|
| [cesp99/fly-chess](https://github.com/cesp99/fly-chess) | FlyWire v783, 134,209 뉴런 / 2.70M 연결 | 배선·부호 고정, **leak과 연결 강도 학습**. Lichess 5,800만 국면 모방학습 → PUCT MCTS 자기대국 | top-1 37.6%, 탐색 붙이면 탐욕 기준선에 +16 =4 −0 | 없음 |
| [NakliTechie/flymate](https://github.com/NakliTechie/flymate) | FlyWire, 138,639 뉴런 / 15.1M 시냅스 | 배선·부호 고정, **인코더 + 시냅스별 이득 + 뉴런별 항상성 + 디코더 학습** | Stockfish 최선수 일치 29.8%, skill 1 격파 | **없음** |
| [Aananda-giri/fly-chess](https://github.com/Aananda-giri/fly-chess) | MaleCNS v1.0, 166,606 뉴런 / 25.57M 엣지 | 커넥톰 완전 고정, 위에 **학습되는 "cortex" 이식 (238만~1,380만 파라미터)** | **Elo 주장 거부.** "8국 7승 1패는 표본이 너무 작다"고 명시 | **있음** — lesion / no-graft / no-senses / relay-permute |
| [lduo8438-max/Chessfly](https://github.com/lduo8438-max/Chessfly) | MaleCNS v1.0, 166,700 뉴런 / 25,582,938 연결 | **전부 고정, 학습 없음.** LIF, 렌더된 체스판 → R1-6/R8, descending 960개로 수 점수화 | **보고 안 함** | **있음** — fixed / random / shuffled-topology |
| FliPy (영상 속 프로젝트) | MaleCNS | 공개 저장소 확인 못 함 | 약 600 Elo 주장, Martin 봇과 대국 | 불명 |

관련 생태계는 [cobanov/awesome-fly](https://github.com/cobanov/awesome-fly)에 정리돼 있다. 체스 외에도
Doom, Mario 64, Minecraft, CARLA, 주식 트레이딩(Stonkfly), 음악(Fly Lab) 등 수십 개가 있고,
대부분 설명에 **"only the readout is trained"**가 붙어 있다.

## 2. 조사에서 드러난 패턴 — 우리 결과와 일치한다

**실력을 보고하는 프로젝트일수록 학습 파라미터가 많다.**
- flymate: 인코더 + 시냅스별 이득 + 디코더 학습 → 29.8% 일치
- cesp99: 연결 강도 학습 + 5,800만 국면 모방학습 + MCTS → 37.6% top-1
- Aananda-giri: 238만~1,380만 파라미터 cortex 이식 → **그럼에도 Elo 주장을 거부**
- Chessfly: **아무것도 학습 안 함 → 실력을 보고하지 않음**

마지막 줄이 핵심이다. 순수하게 고정된 커넥톰만으로 돌린 유일한 프로젝트가 실력 수치를 내놓지 않는다.

**대조군을 두는 프로젝트는 4개 중 2개뿐이고, 둘 다 실력을 주장하지 않는다.**
Chessfly는 shuffled-topology 대조군을 두고, Aananda-giri는 relay-permute·no-graft 개입을 두며 Elo 주장을
명시적으로 거부한다. 반대로 가장 높은 성능을 보고하는 flymate에는 shuffle 대조군이 없다.

우리 실험이 도달한 지점과 같다: **대조군 없이 보면 커넥톰이 일을 하는 것처럼 보이고, 대조군을 넣으면
학습된 부분이 일을 한다는 것이 드러난다.** 우리 P1/P7b에서 real 배선이 matched·global shuffle보다 낮고
뇌 없는 무작위 투영(31.90)이 real central_vnc(28.50~29.10)를 넘었다.

## 3. 영상(SNS 게시물)의 서술 검증

| 주장 | 판정 |
|---|---|
| "약 16만 개의 실제 곤충 뉴런" | 정확 (MaleCNS 166,700) |
| "뇌 배선도를 컴퓨터로 **완벽히 복제**" | **과장.** 공개된 것은 배선(연결·시냅스 수·전달물질 부호)뿐이다. 시상수·이득·발화 문턱 등 생리는 공개되지 않았고 각 구현이 지어낸다. |
| "감각 뉴런에 전기 신호 → 운동 뉴런 반응값으로 수 결정" | 구조 설명으로는 맞다 (Chessfly가 정확히 이 방식) |
| "약 600 Elo" | 600 Elo는 초보자 수준이며, 조사한 공개 저장소 중 Elo를 주장하는 곳은 없다. Aananda-giri는 "표본이 작아 Elo를 매길 수 없다"고 명시한다. |
| "스스로 생각하고 판단하는 생체 기반 AI" | **과장.** 성능을 내는 구현들은 수백만 파라미터를 지도학습·자기대국으로 학습시킨다. 판단하는 주체는 학습된 부분이다. |

## 4. 우리 프로젝트에 대한 함의
1. **새로 시도할 것은 없다.** 우리가 이미 한 비교(real vs matched vs global shuffle, 학습 유무)를
   이들은 대부분 하지 않았고, 한 곳(Chessfly)은 하되 결과를 내놓지 않았다.
2. **우리 음성 결과는 이 생태계와 모순되지 않는다.** 화제가 된 성능은 학습된 판독기/이식 네트워크에서
   나오며, 커넥톰은 고정된 희소 행렬로 쓰인다.
3. 다만 이들은 **과제가 다르다** — 체스는 시각 과제가 아니라 기호 과제이고, 보드를 감각 뉴런에 주입하는
   인코딩 자체가 설계 선택이다. 우리 결과(사물 분류에서는 섞을수록 좋고 움직임에서는 나쁘다)와
   직접 비교되지는 않는다.

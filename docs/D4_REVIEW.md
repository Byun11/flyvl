# FlyVL D4 (FlyViG) — 현재 구조, 경위, 결과 (외부 검토용, 2026-09-29 05:45 기준)

## 0. 한 줄 요약
초파리 시각계 세포 유형 연결도(flyvis, 65유형, 유형 간 연결 581개)를 **Vision GNN(ViG)의 채널 섞기(FFN) 구조**로 넣었다.
지금까지는 **"희소한 유형별 경로" 구조 자체는 도움이 되지만, 실제 초파리 배선이 재배선·무작위 배선보다 낫다는 증거는 없다.**

## 1. 여기까지 온 경위 (왜 이 구조인가)
| 단계 | 한 것 | 결과 | 교훈 |
|---|---|---|---|
| D2 | 초파리 256마리(28 px 칸당 1마리, flyvis 시뮬레이션)로 InternVL3-1B의 비전 토큰을 흉내 → POPE·MME | 선형·MLP-Mixer 어댑터 모두 평균 토큰 수준(POPE 58 vs ViG 87.9), **fly = pixel = 바닥** | 최종 토큰은 자기 칸 픽셀로 R² 0.002 → 칸 단위 학생은 원리상 불가. 모든 팔이 바닥이면 판별 불가 |
| 사다리 | 목표를 InternViT 층별로 내려 선형 복원력 측정 | 초파리 특징은 흔들린 픽셀보다 ViT 4~6층에 훨씬 가까움(+0.13 R²), 그러나 **같은 크기 고전 V1 에너지 뱅크와 차이 0**(+0.0002 [−0.001, +0.002]) | 초파리 = 좋은 초기 시각 필터지만 고전 필터와 동급 |
| D3 | 초파리 눈을 가진 에이전트가 저대비 표적을 쫓아 시선 고정 → VLM이 읽기(폐루프) | **모든 눈(flyvis/HR/프레임차이)이 가만히 있는 에이전트 수준**, 읽기 우연 수준 | 과제가 풀리지 않으면 판별 불가(바닥) |
| D4 설계 | 초파리를 시뮬레이션하는 대신 **배선을 아키텍처 사전 구조로** 사용 | — | 공간 연결은 97%가 3기둥 이내 = 국소성 사전 구조라 버리고, **세포 유형(채널) 축**에만 사용 |

## 2. 현재 구조 (FlyViG, `flyvl/flyvig.py`)
- 노드: 16×16 패치(256개). 채널: 65유형 × 3 = 195 (ViG-Ti 폭 192와 비슷). 블록 6개, KNN k = 9.
- 한 블록 = **공간 메시지** (ViG Grapher: fc → 특징 공간 동적 KNN → max-relative 그래프 합성곱 → fc) + **채널 메시지** (FFN).
- **유형 그래프 FFN** (핵심): 유형 u의 은닉 유닛(유형당 12개)은 u 자신과 **연결도에서 u로 들어오는 유형들**의 채널만 입력으로 받고(마스크),
  출력은 u의 3채널로만 간다(블록 대각). 즉 유형 사이 정보 교환은 실제 연결도 모양으로만 일어난다.
- **시간 상태**(영상용): 블록 출력을 유형별로 누적 s_t = (1 − α)·s_{t−1} + α·out_t, α = sigmoid(유형별 학습값).
- 정규화: 유형별 GroupNorm(65그룹, eps = 1.0). 줄기(stem)만 BatchNorm2d.
- 변형 (입력 경로 / 공간 메시지):
  - **V1**: 패치 임베딩을 광수용체 R1~R8 채널(24개)에만 입력 / 공간 메시지도 유형별(그룹 65)로 → 유형 사이 교환은 FFN 그래프로만.
  - **V2**: 입력은 모든 채널 / 공간 메시지는 유형별.
  - **V3**: 입력은 모든 채널 / 공간 메시지는 원래 ViG(밀집) → "ViG의 밀집 FFN을 연결도 희소 FFN으로 교체한 것".
- 비교 조건 (공간·시간·학습 설정 동일, FFN만 다름):
  - `real` 실제 연결도 / `rewired` 입·출차수 보존 재배선(seed마다 다른 그래프, 실제와 30% 겹침) /
    `random` 같은 연결 수 무작위(16% 겹침) / `dense_small` 같은 파라미터 수의 밀집 FFN / `dense` 밀집 FFN(4×) / `vig` 원래 ViG.

## 3. 사전 등록과 도중 변경 (모두 해당 결과를 보기 전에 `PROTOCOL_D4_flyvig.md`에 기록)
| 부록 | 내용 | 이유 |

| A | 스텝 6,600 → 2,500 (모든 조건) | 예산 60 GPU시간 초과 |
| B | 채널별 BatchNorm → 유형별 GroupNorm | 입력이 닿지 않은 유형 채널이 거의 상수 → 평가 모드에서 한 클래스만 출력(17.7% → 1.0%) |

| D | 영상 난이도 구간 [30%, 90%] (원래 ViG 기준), 건너뛰면 미리 정한 중간 대비 | D3 교훈(바닥 방지) |

| F | **주 과제를 CIFAR-100으로 추가** (사용자 결정: 목표가 좋은 이미지 백본), 영상과 둘 다 진행 | — |
| G | CIFAR 1단계: V1/V2/V3 중 **real과 rewired 검증 평균**으로 V3 선택 | real만으로 고르면 real에 유리한 편향 |
| H | V3W: FFN 은닉 12 → 139로 넓혀 ViG와 파라미터 맞춤 (2.963M vs 2.959M) — **등록했지만 아직 실행 안 함** | 크기가 다른 비교 보완 |

## 4. 결과

### 4-1. CIFAR-100 (V3, seed 1·2·3, 100 에폭, 학습 45k / 검증 5k / 테스트 10k) — 15회 중 14회 완료 (vig seed 3 진행 중)
| 조건 | seed 1 | seed 2 | seed 3 | 평균 | 활성 파라미터 |
|---|---|---|---|---|---|
| vig | 69.59 | 69.63 | (진행) | 69.61 | 2.96M |
| **real** | 68.20 | 69.14 | 69.09 | **68.81** | 1.29M |
| rewired | 68.61 | 68.89 | 68.82 | 68.77 | 1.29M |
| random | 68.72 | 69.02 | 69.05 | 68.93 | 1.29M |
| dense_small | 66.90 | 68.57 | 67.87 | 67.78 | 1.29M |

| 비교 | seed별 | 평균 | 95% CI |
|---|---|---|---|
| real − rewired | −0.41, +0.25, +0.27 | +0.04 | [−0.38, +0.48] |
| real − random | −0.52, +0.12, +0.04 | −0.12 | [−0.57, +0.37] |
| real − dense_small | +1.30, +0.57, +1.22 | +1.03 | [+0.57, +1.50] |
| real − vig (seed 1·2) | −1.39, −0.49 | −0.94 | [−1.51, −0.35] |

- **위상(초파리 배선) 효과 없음.** real ≈ rewired ≈ random (±0.5%p 안).
- **희소 구조 효과**: 연결도 종류와 무관하게 희소 FFN이 같은 크기 밀집 FFN보다 약 +1%p(방향 3/3, CI 하한 0.57 < δ라 등록 기준은 미달).
- ViG 대비: 파라미터 44%로 −0.9%p.
- 참고 CIFAR 1단계(seed 0, 30 에폭, 검증): V1 real/rewired 54.7/55.7, V2 59.3/59.1, V3 64.2/64.0, V3 dense_small 64.6, vig 67.8.

### 4-2. 영상 (등록한 원래 주 과제, V1 설계, 합성, 64 px × 25 프레임, 16분류, 우연 6.25%)
- `fg16` 전경-배경: 배경 전체가 흐르고 한 칸만 다르게 움직임. 대비 0.015~0.04 (원래 ViG 38.7%로 보정).
- `mix16` 움직임 vs 깜빡임: 한 칸은 움직이고 한 칸은 깜빡이기만 함. 대비 0.01~0.03 (원래 ViG 48.1%로 보정).

| 학습 2,100개, seed 0/1/2 (test %) | real | rewired | random | dense | dense_small | vig |
|---|---|---|---|---|---|---|
| fg16 | 94.2 / **66.6** / 95.8 | 97.8 / 95.6 / 95.8 | 98.0 / 97.9 / 95.0 | 53.1 / 55.4 / 70.0 | 58.4 / 80.7 / 59.4 | **38.7** / 99.3 / 99.1 |
| mix16 | 71.0 / 61.1 / 67.7 | 65.2 / 69.9 / 51.1 | 66.7 / 60.8 / 40.2 | 12.9 / 7.4 / 12.9 | 44.8 / 26.4 / 20.2 | 48.1 / 56.4 / 56.2 |

- 등록 판정: 두 과제 모두 **위상 효과 없음**. mix16은 real이 평균 최고(real − rewired +4.5 [+2.8, +6.3], − random +10.7 [+8.8, +12.7])지만
  seed 1에서 rewired가 앞서 "3/3 양수" 미달. fg16은 real seed 1이 학습 실패(66.6)해 real이 오히려 낮음.
- **희소 유형 경로 구조(어떤 연결도든)가 밀집 FFN 버전과 원래 ViG를 크게 이김** (mix16: 희소 40~71% vs vig 48~56% vs dense 7~13%).
- **seed 간 편차가 매우 큼**: 같은 조건에서 학습이 가끔 실패(fg16 vig 38.7 vs 99.3, fg16 real 66.6). 2,500스텝 예산·학습 불안정 의심.
- 학습 300개 조건: 진행 중. **mix16 첫 두 회가 real 7.6%, rewired 6.3%로 우연 수준** — 보정을 학습 2,100개로만 해서 300개 조건은 바닥일 가능성.

## 5. 현재 해석 (범위를 좁혀서)
1. 초파리에서 영감받은 **"희소 유형별 경로(+ 광수용체 입력 + 유형별 시간 상태)" 구조는 효과가 있다**: 움직임 영상에서 원래 ViG·밀집 버전보다 크게 높고,
   CIFAR에서는 파라미터 대비 효율적이다(같은 크기 밀집보다 +1%p).
2. 그러나 그 효과는 **실제 초파리 연결도가 아니라 희소 구조 자체**에서 온다. 같은 구조에 재배선·무작위 연결도를 넣어도 대부분 재현된다
   (CIFAR real − rewired +0.04%p). 이는 flyvis에서 같은 초기값으로 비교하면 위상 효과가 사라진다는 Topological Sensitivity 보고와 방향이 같다.
3. mix16에서 real이 평균 최고라는 신호는 있으나 seed 편차가 커서 확정 불가.

## 6. 알려진 약점 (검토 요청 포인트)
1. **갈림길이 많다.** 스텝 수, 정규화 두 번, 난이도 규칙, 주 과제 변경, 변형 3개, 넓히기. 모두 결과 전에 기록했지만, 우연히 좋은 쪽을 고를 위험이 누적된다.
   단, real / rewired / random은 항상 동일 처리라 **"초파리 배선이 특별한가"** 결론은 이런 선택에 덜 민감하고, **"희소가 밀집보다 낫다"** 결론이 더 민감하다.
2. **seed 3개 + 불안정한 영상 학습**: 학습 실패 한 번이 판정을 좌우. 부트스트랩 CI는 테스트 표본 변동만 반영하고 seed 변동은 반영하지 않는다.
3. **크기 비교**: 2단계 V3(1.29M)는 ViG(2.96M)보다 작다. 크기를 맞추는 방법으로
   (a) FFN 은닉만 넓히기(V3W, 등록됨), (b) **"마리" 단위**(회로 K벌을 나란히, K = 1·2·4, 각 크기마다 파라미터 맞춘 ViG와 비교) 중 어느 쪽이 타당한가.
4. **학습 300개 조건이 바닥**일 가능성 → 계속 돌릴지, 데이터량 조건을 바꿀지.
5. KNN 이웃 선택은 모든 채널을 보고 정하므로 유형 사이 정보가 약하게 섞인다(V1).
6. 영상 과제는 합성이다. 현실 영상 일반화는 미검증.
